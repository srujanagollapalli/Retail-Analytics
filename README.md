# Retail Analytics

## Project Overview

This project analyzes retail sales data using Python and data science techniques.

## Objectives

- Analyze retail sales performance
- Study regional sales
- Analyze product categories
- Identify top-performing products
- Analyze profit and quantity
- Understand monthly sales trends
- Generate business insights

## Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Excel

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Visualization
5. Business Insights
6. Report Generation

## Analysis Performed

- Region-wise Sales Analysis
- Category-wise Sales Analysis
- Product-wise Sales Analysis
- Profit Analysis
- Monthly Sales Trend
- Quantity Analysis
- Sales vs Profit Analysis

## Files

- `Retail_Analytics.ipynb` – Complete analysis notebook
- `Retail_Analytics_Sample_Data.xlsx` – Dataset

## Outcome

The project provides insights into sales, profit, product performance and regional retail performance.
